Word, or
sentence?

How Dodoma captures what you type, where it decides a mistake begins, and why it is neither one word at a time nor the whole line.

10 SLIDES · CAPTURE & SEGMENTATION
00The Short Answer

Neither. It fixes a trailing run.

Both obvious answers are wrong, and each fails in a way you would notice immediately.

Word by word TOO SMALL
One word is barely any evidence. hs is meaningless in both languages; ha is real in one. Judging words alone means constant wrong calls on short ones.
Whole line TOO BIG
You often write in both languages in one line. Rewriting everything would destroy the half that was already correct.
A trailing run USED
Start at the caret, walk backwards while the evidence holds, and rewrite only that stretch. Everything before it is left untouched.

The run always ends at the caret — never in the middle of the line — because the fix is performed with backspaces, which can only delete backwards from where you are.

01Capture

It stores keys, not words.

Nothing is read off your screen. A system-wide event tap records each keystroke as it happens, and for each one keeps four things:

FieldExampleWhy it is needed
keycode4The physical key. Identical in both layouts — this is what makes the original intent recoverable.
modifiersshift, capsCaps Lock and Shift produce different Arabic output; both must be replayable.
produced text"h"What actually landed on screen, so the delete count is exact.
timestamp…8412Drives the one-second pause that triggers evaluation.

Nothing is written to disk and nothing leaves the machine. The buffer holds at most 200 keys and lives only in memory.

02Boundaries

Thirteen ways the buffer empties.

The buffer is not "everything you typed today" — it is the current thought. Anything that means you moved on clears it, and after a clear there is nothing to fix.

You moved the caret
  • Return — sent the message
  • Tab, Escape
  • Arrow keys, Home, End, Page keys
  • A mouse click anywhere
Context changed
  • Switched app or focus
  • Changed input source
  • A ⌘ or ⌃ shortcut
  • 10 seconds of not typing
Safety
  • Secure input — also purges the keystroke log
  • Buffer overflow past 200 keys
  • After a fix is applied

This is why nothing happens in a chat box when you type and press Return straight away: sending clears the buffer before the one-second pause ever arrives.

03Tokens

Words are just spaces in the key stream.

On the pause, the buffered keys are split on whitespace keys. No dictionary is consulted yet — a "word" at this stage is only a run of keys between two spaces.

buffer → tokens · the region always reaches the caret

Trailing spaces belong to the region too. If you typed a space after the last word, the fix must delete it and retype it — otherwise the count would be off by one and the correction would land in the wrong place.

04The Walk

Backwards from the caret, one word at a time.

This is the part that is word by word. Starting at the last token and moving left, each word is asked one question — and the walk continues only while the answer keeps coming back the same way.

05The Failure

When a real word appears by accident.

Typing what is pr dojs on the Arabic layout produces four Arabic tokens. Three are nonsense — but حق is a genuine Arabic word, scoring 1.00 dictionary coverage.

# the walk, right to left يختس take dojs حق STOP real Arabic word هس · never reached صاشف · never reached

The run became one four-letter token — under the six-letter minimum to rewrite — so the line was merely offered as a suggestion and stayed wrong.

What you saw BUG

صاشف هس حق يختس

A wall went up in the middle of one English sentence, because a rule meant to protect bilingual writing cannot tell a deliberate Arabic word from an accidental one.

06The Fix

Ask the question about the whole run.

Where the walk stops, the run it produced is now scored as a whole and compared against each longer run. The longer one is taken only if it reads clearly better under the other layout.

BufferStop at the wordReach past itChosen
صاشف هس حق يختس 0.40 0.60 whole run → what is pr dojs
check this hgsghl 0.91 −0.23 last word only → السلام

The same number settles both. Pulling real English into the region destroys its score, so bilingual text is protected by arithmetic rather than by a rule that has to guess which words you meant.

07Scoring

A run is scored as one piece of text.

Once the run is chosen, its two readings are scored whole — not word by word — so a single odd word cannot swing the verdict on its own.

صاشف هس حق يختس AS TYPED

Only حق counts — one accidental word in four.

what is pr dojs OTHER LAYOUT

"what" and "is" carry it; "pr" and "dojs" are not words and it still wins.

Gap 0.60, against the 0.40 a silent rewrite requires — so it acts without asking.

08In One Sentence

Words find the edge. The run makes the call.

Both levels are used, and each does the job the other cannot.

Word level WHERE
Walking backwards word by word is how the boundary is found — how far back the mistake goes, and where deliberate text begins.
Run level WHETHER
Scoring the whole run is how the decision is made — rewrite silently, offer a suggestion, or do nothing at all.

And the run is never longer than what you typed since your last pause, click, or Return — so a fix can only ever reach back into the sentence you are still in the middle of.
